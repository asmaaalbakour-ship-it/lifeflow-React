## Features

- 🎯 Add, complete, and delete goals
- 🌱 Create and track daily habits
- 📅 Calendar for selecting and tracking daily progress
- 🔥 Habit streak tracking
- 🧠 Focus Mode with customizable timer (15, 25, or 50 minutes)
- 📝 Create and delete personal notes
- 💾 Save habits and notes using LocalStorage
- 📊 Dashboard with goals and habits statistics
- 📈 Progress bars for goals and daily habits
- 🧭 Smooth navigation between sections
- 📱 Responsive design for different screen sizes
- 🎨 Clean green and beige user interface
